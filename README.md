## 📚 Syllabus

| 🧠 Module | 📖 Topic | ⚡ Key Concepts (Topic → Sub-topics) |
|:---------:|----------|--------------------------------------|
| **01** | **Control Flow** | • **Conditionals** → `if`, `elif`, `else`, nested if<br>• **Loops** → `for` loop, `while` loop, nested loops<br>• **Loop Control** → `break`, `continue`, `pass` |
| **02** | **Strings** | • **Basic Operations** → indexing, slicing, concatenation, repetition<br>• **Methods** → `upper()`, `lower()`, `strip()`, `split()`, `join()`, `replace()`, `find()`, `count()`<br>• **Formatting** → `format()`, f-strings |
| **03** | **Lists** | • **Accessing** → indexing, slicing, negative indexing<br>• **Methods** → `append()`, `extend()`, `insert()`, `remove()`, `pop()`, `sort()`, `reverse()`, `clear()`<br>• **Comprehension** → list comprehension, nested lists |
| **04** | **Tuples** | • **Basic** → creating, indexing, slicing<br>• **Methods** → `count()`, `index()`<br>• **Features** → immutable, packing, unpacking, tuple vs list |
| **05** | **Dictionaries** | • **Accessing** → `keys()`, `values()`, `items()`, `get()`<br>• **Modifying** → `update()`, `pop()`, `popitem()`, `clear()`, `copy()`<br>• **Comprehension** → dict comprehension, nested dict |
| **06** | **Sets** | • **Basic** → `add()`, `remove()`, `discard()`, `clear()`<br>• **Operations** → `union()`, `intersection()`, `difference()`, `symmetric_difference()`<br>• **Relations** → subset, superset, disjoint |
| **07** | **Functions** | • **Definition** → `def`, parameters, arguments, return<br>• **Types** → default args, keyword args, `*args`, `**kwargs`<br>• **Scope** → global, local, nonlocal<br>• **Lambda** → lambda functions |
| **08** | **File Handling** | • **Modes** → `r`, `w`, `a`, `r+`, `w+`, `a+`<br>• **Operations** → `open()`, `read()`, `write()`, `append()`, `close()`<br>• **Methods** → `readline()`, `readlines()`, `writelines()`<br>• **Context Manager** → `with` statement<br>• **File Types** → text, CSV, JSON |
| **09** | **Exception Handling** | • **Blocks** → `try`, `except`, `else`, `finally`<br>• **Raise** → `raise` exception<br>• **Built-in Exceptions** → `ValueError`, `TypeError`, `FileNotFoundError`, `ZeroDivisionError`, `IndexError`, `KeyError` |
| **10** | **Modules & Packages** | • **Import** → `import`, `from import`, `as`<br>• **Built-in Modules** → `math`, `random`, `datetime`, `os`, `sys`, `json`, `csv`<br>• **Custom** → creating modules, `__name__` variable<br>• **External** → `pip install`, `venv` |
| **11** | **OOP Basics** | • **Class** → `class`, object, attributes, methods<br>• **Constructor** → `__init__()`, `self`<br>• **Inheritance** → single, multiple, multilevel, `super()`<br>• **Polymorphism** → method overriding<br>• **Encapsulation** → private (`_`), protected (`__`)<br>• **Special Methods** → `__str__()`, `__repr__()` |
